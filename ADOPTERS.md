# TiKV adopters

The [TiKV adopters page](https://tikv.org/adopters/) documents organizations
using TiKV, both directly and as the storage layer for TiDB. Its
[source](https://github.com/tikv/website/blob/master/content/adopters.md) is
maintained in the TiKV website repository.

The following organizations are listed there as using TiKV independently of TiDB:

- JD Cloud & AI
- Shopee
- LY.com
- Zhuan Zhuan
- Meituan-Dianping
- Ele.me
- Yidian Zixun
- KuGou
- Meitu

These are documented adoption examples, not a claim about each organization's
current deployment. See the official page for details and the additional TiDB
adopters. To add or update an adopter, submit a pull request to the
[website source](https://github.com/tikv/website/blob/master/content/adopters.md)
and keep this summary in sync.
